## 1. 개요

### 1.1 목적

시나르마스(Sinar Mas) 그룹의 투자/관리 법인 Corfortune과의 미팅에서, 어포메이션을 **"K-브랜드 인도네시아 진출의 OS(운영체제)"**로 포지셔닝하는 전략적 랜딩페이지를 개발한다.

단순 제품 소개가 아닌, **"시나르마스의 인프라(하드웨어) + 어포메이션의 AI 솔루션(소프트웨어) = K-커머스 독점 파이프라인"** 구조를 시각적으로 압도하는 방식으로 전달한다.

### 1.2 배경

**시나르마스(Sinar Mas)**
- 인도네시아 재계 서열 2~4위의 거대 재벌 그룹
- 보유 인프라: 부동산(BSD City 등), 물류 네트워크, 오프라인 유통(마트/리테일)
- Pain Point: "인프라는 넘치는데, 무엇을 채워야 돈이 되는가?"
- "한국 브랜드 좋다는 건 아는데, 시장 전체를 먹을 독점 파이프라인은 없나?"

**Corfortune (싱가포르)**
- 시나르마스 자금 운용 싱가포르 법인
- 김한엽 대표 - 본사에 "그룹 차원의 신사업(JV/투자)" 거리로 포장 가능한 모델이 필요
- 단순 납품 계약이 아닌, 체계적이고 독점적인 파이프라인을 원함

**어포메이션(Afformation) - 2021년 설립**
- AI 기반 인플루언서 마케팅 자동화 플랫폼 운영사
- 3대 사업: 챗닥(병원 마케팅), 해외환자유치 MSO, ScoutManager SaaS
- ScoutManager: LLM 기반 인플루언서 발굴/분석/섭외/콘텐츠/정산 올인원 SaaS
- 누적 100억+ 병원 매출 기여, 20+ 파트너 의료기관
- 투자사: Paratus Investment, LINE, KAIA, SentBe, NICE정보통신
- 글로벌 진출: 대만, 일본, 영미권

**핵심 전략: "The K-Market Gateway"**
- 물건을 파는 것이 아니라, 시나르마스 인프라 위에 어포메이션 AI 솔루션을 이식하는 파트너십 제안
- Key Message: "우리는 인도네시아 진출의 OS(운영체제)다"
- 최종 비전: 인도네시아 합작 법인(JV) → K-브랜드 독점 유통 소프트웨어 & 플랫폼

### 1.3 관련 문서

- 어포메이션 공식: https://afformation.co.kr/
- ScoutManager: https://scoutmanager.io/
- 디자인 문서: `docs/02-design/features/sinarmas-landing.design.md` (예정)

### Section 3: The Afformation Loop - 핵심 순환 시스템 (최대 임팩트)

**컨셉**: 페이지 전체에서 가장 압도적인 섹션. 어포메이션의 핵심 경쟁력인 "끊기지 않는 순환 시스템"을 인터랙티브 SVG로 시각화.

```
┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│            " 어포메이션 루프 "                                   │
│      "한 번 돌기 시작하면, 멈출 수 없는 성장 엔진"              │
│                                                                  │
│                  ┌── ① 브랜드 분석 ──┐                          │
│                  │                    │                           │
│         ⑧ 현지화 최적화          ② 진출 전략 수립              │
│              │                        │                          │
│         ⑦ 브랜드 성장            ③ ScoutManager AI              │
│           & 고도화               (인플루언서 발굴                │
│              │                    → 자동 섭외                    │
│         ⑥ 판매 & 유통            → 콘텐츠 생산                  │
│         (시나르마스 시너지)       → 성과 분석                    │
│              │                    → 정산)                        │
│         ⑤ 커머스 세팅                │                          │
│         (TikTok Shop               ④ 광고 시스템                │
│          + Shopee)               (콘텐츠 재가공                  │
│              │                    → 타겟 광고                    │
│              └────── ◆ ──────────┘ → 트래픽 폭발)               │
│                                                                  │
│   ── 글로우 파티클이 경로를 따라 무한 순환 ──                   │
│                                                                  │
│   [각 노드 호버 시 상세 카드 팝업]                               │
│                                                                  │
│   ───────────────────────────────────────────────                │
│   "이 Loop가 성공사례를 만들고 → 더 많은 K-브랜드 유입         │
│    → 시스템이 플랫폼화 → 합작 법인(JV) 구축"                   │
│   ───────────────────────────────────────────────                │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

**8단계 Loop 상세:**

| 단계 | 이름 | 상세 설명 | 아이콘 |
|------|------|----------|--------|
| ① | 브랜드 분석 | 브랜드의 현재 상황, 경쟁사, 인도네시아 시장 적합성을 360도 분석. SWOT, 현지 소비자 분석, 가격 전략 수립 | 돋보기 |
| ② | 진출 전략 수립 | 인도네시아 시장 맞춤 GTM(Go-To-Market) 전략 설계. 타겟 고객 설정, 채널 전략, KPI 수립 | 타겟 |
| ③ | ScoutManager AI | AI로 인도네시아 인플루언서 10,000+명 자동 분석, 브랜드 적합도 매칭, 자동 DM 섭외, 콘텐츠 가이드 제공, 성과 분석, 정산까지 올인원 | 로봇 |
| ④ | 광고 시스템 | 인플루언서 콘텐츠를 재가공하여 Meta/TikTok/Google 광고 집행. AI 기반 타겟팅으로 트래픽 폭발적 확산 | 메가폰 |
| ⑤ | 커머스 세팅 | TikTok Shop, Shopee 인도네시아 스토어 세팅. 인플루언서와 라이브 커머스 협업, 어필리에이트 프로그램 구축 | 쇼핑카트 |
| ⑥ | 판매 & 유통 | **시나르마스 시너지 포인트** - 시나르마스의 물류 네트워크와 온/오프라인 유통 인프라를 활용한 대량 유통 | 트럭 |
| ⑦ | 브랜드 성장 & 고도화 | 판매 데이터 기반 현지화 브랜딩, 현지 니즈 반영한 제품 고도화, 브랜드 인지도 상승 | 차트 |
| ⑧ | 현지화 최적화 | 데이터 기반 지속 최적화. 소비자 피드백 → 제품 개선 → 더 뾰족한 브랜딩 → Loop 재순환 | 순환화살표 |

**디자인 디테일:**
- 배경: 거의 검정에 가까운 다크 + 중앙에 방사형 미세 그래디언트
- SVG 원형 경로: 8개 노드가 원형으로 배치, 각 노드는 글로우 원형 아이콘
- **파티클 플로우**: 경로를 따라 빛나는 파티클이 시계 방향으로 끊임없이 순환
- **노드 호버 시**: 해당 노드 확대 + 상세 설명 카드 팝업 (글래스모피즘)
- **노드 ⑥번 강조**: 시나르마스 로고 컬러(골드)로 특별 하이라이트 → "여기가 시너지 포인트"
- 하단 텍스트: "이 Loop가 성공사례를 만들고..." 부분 → 타이핑 + 글로우 효과
- **모바일**: 세로 스크롤 타임라인으로 변환

- `@layer components` 내부 정의 시 모든 속성이 무시됨 (specificity 0)
